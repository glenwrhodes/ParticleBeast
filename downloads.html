Quick start

Drop the library into your WebGL game. ParticleBeast can own its own canvas, or render straight into your existing WebGL2 context (it saves and restores all GL state it touches).

import { ParticleBeast } from './particle-beast.js';

const beast = new ParticleBeast(myCanvasOrGlContext);
const explosion = await beast.loadEffect('presets/explosion.json');

// when something blows up:
beast.spawn(explosion, { position: [x, y, z], tint: '#ff8833' });

// in your game loop:
beast.update(deltaSeconds);
beast.render(viewMatrix, projectionMatrix);
